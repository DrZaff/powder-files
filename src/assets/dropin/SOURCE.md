# Drop in scene images

Generated images of a fictional mountain, made by the project owner with ChatGPT image generation
(November 2026) for the home page's "Drop in" background. Not a real place, not a resort photo.
The site captions them "Generated image · fictional mountain".

- sky, range, couloir, skis: 1536×1024 layers for the wide-screen parallax (range is smeared downward
  under itself so parallax never opens a gap).
- phone: 1024×1536 portrait version for tall screens.
