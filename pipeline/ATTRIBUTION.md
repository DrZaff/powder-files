# Data attribution

The generated directory combines:

- Wikidata structured data, CC0 1.0: https://www.wikidata.org/wiki/Wikidata:Licensing
- OpenStreetMap data, © OpenStreetMap contributors, ODbL 1.0: https://www.openstreetmap.org/copyright
- A locally maintained Powder Files Bristol Mountain record.

Every canonical record retains source names, source identifiers, source links, collection timestamps, confidence, and field-level provenance. Applications displaying the compact directory must keep an accessible attribution notice for OpenStreetMap-derived records.
